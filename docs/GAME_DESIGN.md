# GAME DESIGN

## 核心循环
观察来球 → 判断时机 → 真人挥拍 → 手势检测 → 角色挥拍 → 宽容击球判定 → 球飞向对面 → AI 回球 → 重复。

## 控制哲学
摄像头不是精确动作捕捉器，而是“体感意图输入”。识别重点：惯用手手腕位置、速度、方向、短时间加速度。第一版动作：左挥、右挥、上/下快速挥。避免要求真实球拍与虚拟球精确重合。

## 击球判定
当球进入玩家的可击球时空窗口，并在窗口内检测到有效 swing，则击球。窗口要宽容；使用 cooldown 防止一次挥拍重复触发。加入可调阈值与平滑。

## 击球结果
MVP 先使用统一可靠回球。随后加入时机评价：Good / Great / Perfect。时机更好可提高速度、角度质量与反馈，不需要严格真实物理。

## 球运动
简化抛射 + 重力 + 人工阻力/速度曲线，使球“快速出拍、明显减速、弧线清楚”。重点是可读性与节奏。

## AI
规则 AI：预测落点 → 移动 → 到位 → 延迟 → 挥拍。MVP AI 要可靠但偶尔失误。不要机器学习。

## 计分
MVP 可使用简化 rally 得分制：落地/出界/未接到则对方得 1 分，随后重新发球。正式规则可在后续版本决定。

## 趣味反馈
击中：清脆声音、短拖影/轻粒子、角色惯性、轻微 camera impulse。挥空：角色略失衡。AI 偶尔跑过头/挥空。反馈不能遮挡球。

## 未来三关（不属于 MVP）
1. 训练馆：慢 AI，教学。
2. 屋顶球场：中等 AI，左右调动、Combo。
3. 冠军竞技场：Boss，速度更快、会扣杀，胜利喜剧动画。
