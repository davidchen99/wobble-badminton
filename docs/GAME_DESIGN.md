# GAME DESIGN

## 核心循环
观察来球 → 判断时机 → 真人挥拍 → 手势检测 → 角色挥拍 → 宽容击球判定 → 球飞向对面 → AI 回球 → 重复。

## 控制哲学
摄像头不是精确动作捕捉器，而是“体感意图输入”。识别重点：掌心（9 号关键点，挥拍弧线大于手腕）位置、速度、方向、短时间加速度。第一版动作：左挥、右挥、上/下快速挥。避免要求真实球拍与虚拟球精确重合。

意图分离：手部慢速位移 = 移动意图（角色横向跟手找球，纵向蹲起微调），快速挥动 = 挥拍意图。玩家因此可以"移动 → 到位 → 挥拍"，而不是站桩。允许握拍/握轻物挥动，识别只关心手本身。

## 击球判定
当球进入玩家的可击球时空窗口，并在窗口内检测到有效 swing，则击球。窗口要宽容；使用 cooldown 防止一次挥拍重复触发。加入可调阈值与平滑。

## 击球结果
MVP 先使用统一可靠回球。随后加入时机评价：Good / Great / Perfect。时机更好可提高速度、角度质量与反馈，不需要严格真实物理。

## 球运动
简化抛射 + 重力 + 人工阻力/速度曲线，使球“快速出拍、明显减速、弧线清楚”。重点是可读性与节奏。
默认节奏为高慢球：AI 回球与发球飞行 1.6~2 秒，给新手留足反应时间；球速作为可调难度参数（首轮实测证明快节奏对新手不可玩）。

## 新手引导
进入游戏后先进入 4 步引导，每步实时显示识别反馈，全部完成才开赛：
1. 举起手/握拳/握拍，让摄像头看到（骨架点亮即确认）。
2. 向左挥一次（检测到 left swing 打勾）。
3. 向右挥一次（检测到 right swing 打勾）。
4. 提示站位与画幅（后退让上半身进入预览画面），随后自动开球。
引导可随时跳过（空格），但默认对新玩家开启。

## AI
规则 AI：预测落点 → 移动 → 到位 → 延迟 → 挥拍。MVP AI 要可靠但偶尔失误。不要机器学习。

## 计分
MVP 可使用简化 rally 得分制：落地/出界/未接到则对方得 1 分，随后重新发球。正式规则可在后续版本决定。

## 趣味反馈
击中：清脆声音、短拖影/轻粒子、角色惯性、轻微 camera impulse。挥空：角色略失衡。AI 偶尔跑过头/挥空。反馈不能遮挡球。

## 未来三关（不属于 MVP）
1. 训练馆：慢 AI，教学。
2. 屋顶球场：中等 AI，左右调动、Combo。
3. 冠军竞技场：Boss，速度更快、会扣杀，胜利喜剧动画。
