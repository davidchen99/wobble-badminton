# GAME DESIGN

## 核心循环
观察来球 → 移动到位（手移/键盘）→ 握拳/快挥 → 手势检测 → 角色挥拍 → 宽容击球判定 → 球飞向对面 → AI 回球 → 重复。赢下比赛 → 荣誉结算 → 晋级下一关 → 通关新手轨解锁专业轨。

## 控制哲学
摄像头不是精确动作捕捉器，而是"体感意图输入"。游戏提供两种操控模式（M 键随时切换，屏幕角落常显当前模式）：

**模式一 · 空手模式（默认）**
- 握拳 = 击打。检测手指弯曲度（指尖收拢），带迟滞防抖。击打就是正板直直往前打，像练习球：不分正反手、不按手位变方向、没有大斜线，角色一个标准挥拍动作。
- 连握两次 = 扣球：第一握立即普通击打（不为等第二握加延迟）；第二握（连握窗口 600ms 内）把空中的球"补"成扣杀——只要球是自己刚击出且仍飞向对面即成立（M13 起取消 0.6s 补刀时限），角色跳起、球更快更平 + 闪光。
- 手部慢速位移 = 移动意图：左右=横向跑位；手在画面里的大小变化（离摄像头远近）= 前后移动。引导第 1 步校准基准手大小。
- 快速挥动不产生击打（避免和移动混淆），仅用于模式二。

**模式二 · 键盘 + 持物模式**
- WASD = 前后左右移动。
- 手持遥控器/拍子快速挥动 = 击打（掌心 9 号关键点速度检测）。
- 挥拍方向/手位不影响回球方向，同样正板直打。

两模式共用移动范围与宽容击球窗口，只是输入源不同。

## 击球判定
当球进入玩家的可击球时空窗口，并在窗口内检测到有效击打输入（空手=握拳，持物=快挥），则击球。窗口宽容且对新手友好：球飞到角色附近时随手撩一下即可打到，宁可略宽不可频繁漏球；用迟滞与 cooldown 防止一次握拳/挥拍重复触发。加入可调阈值与平滑。
放宽的原则是**时间宽、空间适中**：击球时机窗口宁宽勿严（早挥/晚挥都给容错），但空间上仍要求球在角色附近——保住移动跑位的意义，避免站着原地撩全场。前后（深度）方向的容差比左右更宽，因为"手大小=前后"是最不直觉的输入。
握拳检测的手感红线（M13 实测定调）："张开"判定必须宽松（稍松即算张开），否则连握第二次永远注册不上，引导第三步卡死、实战扣球触发不出。

## 击球结果
正板直打：回球方向固定朝对方场地，不随输入方向变化，落点在对方站位附近小散布。
- 普通击打（握一下 / 快挥）：原地标准挥拍。
- 扣球（连握两次触发）：角色明显跳起扣杀——跳起幅度要夸张（跳跃峰值 ~0.85m、落地压缩狠），与普通击打隔屏可辨；球更快更平、带闪光特效。跳起只是演出，判定窗口与时机不变，不能"跳了反而更难打"。
随后版本再考虑 Good/Great/Perfect 时机评价。

## 球运动
简化抛射 + 重力 + 人工阻力/速度曲线，使球“快速出拍、明显减速、弧线清楚”。重点是可读性与节奏。
默认节奏为高慢球：新手轨开局 1.9 秒/趟，AI 回球与发球给新手留足反应时间；球速作为关卡难度参数递进；扣杀飞行时间按关卡可配（新手王冠 0.95s 可接，专业魔王 0.7s 致命）。

## 新手引导
整块黑色遮罩的全屏引导界面：中央**左右对照大号动画** + 实时识别反馈 + 步骤圆点。
左右对照：左侧演示手部动作（张开↔握拳），右侧简笔小人同步演示游戏内结果——握一下，小人挥拍击打；握两下，小人跳起扣杀（动作明显更快）。让玩家一眼建立"我的动作 → 小人干什么"的映射。
共 4 步，全部完成才开赛：
1. 举起手让摄像头看到（骨架点亮即确认，同时校准基准手大小）。
2. 握拳一次 = 击打（检测到握拳打勾）。
3. 连握两次 = 扣球。**通过条件放宽（M13）：1.2 秒内任意两次握拳即算学会**——教学是建立概念，不是考操作精度；文案明确"握紧→松开→再握紧，连着来两下"。
4. 提示站位与移动（手左右移=跑位、手大小变=前后），随后进入赛制选择并开球。
引导可随时跳过（空格），默认开启；帮助层可随时重进引导。

## AI
规则 AI：预测落点 → 移动 → 到位 → 延迟 → 挥拍。AI 要可靠但偶尔失误，失误率与球速随关卡递进。不要机器学习。

## 计分与赛制
开局选择赛制：6 分快局（默认）或 21 分标准赛（右上角入口）。均为先到分数直接获胜，不设 deuce 加分。回合内落地/出界/未接到则对方得 1 分，得分者发下一球。分出胜负后进入荣誉结算，按 R 开新局。

## 荣誉体系与结算
- 单场胜利：结算画面 + 赢家庆祝（乱跳）、输家坐地发呆；首次获胜颁发小奖杯（领奖时刻）。
- 闯关晋级：打赢当前关卡进入下一关；同一轨道内当局连续递进。
- 冠军时刻：轨道三关全通关 → 角色站上 1/2/3 领奖台最高处，领奖台模型做得有意思，画风保持低模呆萌不变。
- 解锁时刻：通关新手轨王冠 → 领奖台后播"专业玩家登场"小动画（紫色荧光对手出场）→ 解锁专业轨。解锁状态用 localStorage 持久化，解锁一次永久有效（刷新不失效）。

## 观众系统（递进式，M13）
观众数量 = 不用 UI 的进度条：玩家余光一扫就知道打到第几关。
- 新手·第 1 关（黑帽）：两边各 2 个彩色小人，稀稀拉拉（小区野球场感）。
- 新手·第 2 关（橙帽）：两边各 2 排 × 4 人，开始像正式比赛。
- 新手·第 3 关（王冠决赛）：两边各 3 排满场 + 拉横幅（"加油！"），大场面。
- 专业·第 1/2 关：保持满场规格（通关者排面不退）。
- 专业·第 3 关（魔王，彩蛋）：三面环绕体育场——对面立三层大看台与两侧连成一片，满员 + 多条横幅 + 人群欢呼更响。
实现约束：抽象低模彩色小人（与运动员同画风）；实例化渲染（全部观众 ≤4 个绘制调用）；配色偏暗、动作幅度小，绝不抢球的戏（ART_DIRECTION 红线）；进球/扣杀时集体跳起欢呼，平时静止微动。

## 帮助系统
左上角常驻 "?" 帮助图标：鼠标可点，快捷键 H/F1 呼出。内容：两种模式操作说明 + 动作简图小动画 + "重新进入新手引导"入口。

## 动作简图
帮助层与新手引导中的动作用 Canvas 程序化绘制的极简动画演示（简笔手 + 简笔小人），不用视频素材，一眼看懂。引导版为黑底全屏大号左右对照动画。

## 趣味反馈
击中：清脆声音、短拖影/轻粒子、角色惯性、轻微 camera impulse（扣球不晃镜头，M12 实测修正）。挥空：角色略失衡。AI 偶尔跑过头/挥空。得分/扣杀时人群欢呼爆发（平时安静）。反馈不能遮挡球。

## 双难度轨（当前计划，四轮定稿）
两条轨道，各三关，帽子即难度符号；HUD 关卡标识区分"新手 · 第 X 关 / 专业 · 第 X 关"：
1. **新手轨（默认）**：黑帽新手 → 橙帽好手 → 王冠 Boss。整体慢而宽容，首次玩家可通关。
2. **专业轨（通关新手王冠解锁）**：紫影 → 紫电 → 魔王。同一角色紫色递进加深 + 荧光感（emissive 发光），看起来就凶狠；球速/反应/扣杀全面加强。
专业轨解锁后，开局赛制选择层出现轨道入口（新手/专业可切换）。

## 难度曲线与心流参数（设计评审定调 2026-08-12；四轮定稿双轨化）
目标：让新手落在"有点难但能赢"的心流区间，挑战随关卡与玩家成长递增。
- 对局时长：6 分快局约 2~4 分钟（体感游戏单局甜点 3~5 分钟，手臂疲劳是硬约束）；21 分标准赛约 8~15 分钟，留给想认真打的玩家。
- 新手轨目标：**首次玩家能完整通关**（每关首战胜率 60~70%，王冠允许多试两次）；专业轨目标：通关玩家"有点难但能赢"（首战胜率 30~50%）。
- 落点递进：第一关"球找人"（AI 回球落点偏向玩家站位，保送连贯 rally），后续关卡逐步"人找球"（落点散布加大，逼玩家跑动）。
- 关卡数值（初值，实测微调；专业轨经评审修正，紫影强度 ≥ 新手王冠，平滑交接）：
  | 轨道·关卡 | 球飞行 | AI 失误率 | AI 反应 | 扣杀率 | 扣杀飞行 |
  | --- | --- | --- | --- | --- | --- |
  | 新手·黑帽 | 1.9s | ~25% | ~280ms | 0 | – |
  | 新手·橙帽 | 1.6s | ~15% | ~230ms | 0 | – |
  | 新手·王冠 | 1.3s | ~8% | ~180ms | ~20% | 0.95s（前摇明显、可接） |
  | 专业·紫影 | 1.25s | ~8% | ~170ms | ~25% | 0.9s |
  | 专业·紫电 | 1.1s | ~5% | ~150ms | ~30% | 0.8s |
  | 专业·魔王 | 0.95s | ~3% | ~120ms | ~45% | 0.7s（致命） |
- 深度移动宽容：前后方向击球容差 > 左右方向（见击球判定），第一关以左右跑位为主。
- 扣球不卡关：双握窗口在紧张对打中不一定按得出，新手轨不依赖扣球也能赢。
