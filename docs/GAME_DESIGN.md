# GAME DESIGN

## 核心循环
观察来球 → 移动到位（手移/键盘）→ 握拳/快挥 → 手势检测 → 角色挥拍 → 宽容击球判定 → 球飞向对面 → AI 回球 → 重复。

## 控制哲学
摄像头不是精确动作捕捉器，而是"体感意图输入"。游戏提供两种操控模式（M 键随时切换，屏幕角落常显当前模式）：

**模式一 · 空手模式（默认）**
- 握拳 = 击打。检测手指弯曲度（指尖收拢），带迟滞防抖。击打就是正板直直往前打，像练习球：不分正反手、不按手位变方向、没有大斜线，角色一个标准挥拍动作。
- 连握两次 = 扣球：第一握立即普通击打（不为等第二握加延迟）；若刚击中且 0.35 秒内又握一次，空中的球"补"成扣杀——更快更平 + 闪光。
- 手部慢速位移 = 移动意图：左右=横向跑位；手在画面里的大小变化（离摄像头远近）= 前后移动。引导第 1 步校准基准手大小。
- 快速挥动不产生击打（避免和移动混淆），仅用于模式二。

**模式二 · 键盘 + 持物模式**
- WASD = 前后左右移动。
- 手持遥控器/拍子快速挥动 = 击打（掌心 9 号关键点速度检测）。
- 挥拍方向/手位不影响回球方向，同样正板直打。

两模式共用移动范围与宽容击球窗口，只是输入源不同。

## 击球判定
当球进入玩家的可击球时空窗口，并在窗口内检测到有效击打输入（空手=握拳，持物=快挥），则击球。窗口要宽容；用迟滞与 cooldown 防止一次握拳/挥拍重复触发。加入可调阈值与平滑。

## 击球结果
MVP 正板直打：回球方向固定朝对方场地，不随输入方向变化，落点在对方站位附近小散布。扣球（连握触发）更快更平、带闪光特效。随后版本再考虑 Good/Great/Perfect 时机评价。

## 球运动
简化抛射 + 重力 + 人工阻力/速度曲线，使球“快速出拍、明显减速、弧线清楚”。重点是可读性与节奏。
默认节奏为高慢球：开局 1.8 秒/趟，AI 回球与发球给新手留足反应时间；球速作为可调难度参数（首轮实测证明快节奏对新手不可玩）；关卡提速留给三关版本。

## 新手引导
进入游戏后先进入 4 步引导，每步实时显示识别反馈 + 动作简图小动画，全部完成才开赛：
1. 举起手让摄像头看到（骨架点亮即确认，同时校准基准手大小）。
2. 握拳一次 = 击打（检测到握拳打勾）。
3. 连握两次 = 扣球（检测到双握打勾）。
4. 提示站位与移动（手左右移=跑位、手大小变=前后），随后自动开球。
引导可随时跳过（空格），默认开启；帮助层可随时重进引导。

## AI
规则 AI：预测落点 → 移动 → 到位 → 延迟 → 挥拍。MVP AI 要可靠但偶尔失误。不要机器学习。

## 计分
21 分简化制：先到 21 分直接获胜，不设 20 平加分。回合内落地/出界/未接到则对方得 1 分，得分者发下一球。一方到 21 分出胜负结算画面（赢家乱跳庆祝、输家坐地发呆），按 R 开新局。

## 帮助系统
左上角常驻 "?" 帮助图标：鼠标可点，快捷键 H/F1 呼出。内容：两种模式操作说明 + 动作简图小动画 + "重新进入新手引导"入口。

## 动作简图
帮助层与新手引导中的动作用 Canvas 程序化绘制的极简小动画演示（如简笔手张开↔握拳循环、左右移动箭头），不用视频素材，一眼看懂。

## 趣味反馈
击中：清脆声音、短拖影/轻粒子、角色惯性、轻微 camera impulse。挥空：角色略失衡。AI 偶尔跑过头/挥空。反馈不能遮挡球。

## 未来三关（不属于 MVP）
帽子即难度符号，每关不同 AI 对手：
1. 黑帽新手（训练馆）：慢球、失误多，教学体验。
2. 橙帽好手（屋顶球场）：中等球速，左右调动、Combo。
3. 王冠 Boss（冠军竞技场）：球速快、会扣杀，胜利喜剧动画。
