# MVP / VERTICAL SLICE PLAN

## Milestone 0 — 工程可运行
建立 Vite + TS；Three.js 空场景；基础 HUD；build/typecheck 通过。

## Milestone 1 — 摄像头追踪
授权摄像头；MediaPipe 初始化；显示手关键点/状态；计算手腕轨迹、速度；Debug 调参。

## Milestone 2 — 可玩的静态球场
球场、网、两个低模角色、球、固定镜头；720p 流畅。

## Milestone 3 — 挥拍驱动角色
GestureDetector 产生 swing event；角色立即挥拍；有 cooldown；视觉上有轻惯性。

## Milestone 4 — 击球闭环
球进入辅助击球区 + swing → 击球；球过网/落地/出界；重新发球。

## Milestone 5 — AI Rally
AI 预测落点、移动、回球；玩家可连续对打。

## Milestone 6 — 游戏化
比分、HUD、开始/暂停/重开；基础声音；轻反馈。

## Milestone 7 — 体验修复与新手引导（首轮实测后插入，已完成）
卡顿治理（推理 Worker 化/降分辨率/自适应降频）；高慢球节奏 + 球速参数；掌心采样与挥拍灵敏度；4 步新手引导；大画幅预览与站位指引；身体移动控制；音效升级；Debug 默认隐藏。

## Milestone 8 — 操控重做与 21 分制（二轮定稿，已完成）
双操控模式（空手：握拳击打 + 手大小前后；键盘+持物：WASD + 快挥，M 切换）；正板直打 + 连握扣球；21 分简化制 + 胜负结算；Help 帮助系统 + 动作简图小动画；新手引导改握拳版。

## Milestone 9 — 体验优化与赛制（三轮定稿，已完成）
开局赛制选择（6 分快局默认 / 21 分标准赛，均无 deuce）；跳起扣杀动画（与普通击打一眼可辨）；击球判定放宽（新手友好）；引导重做（黑底全屏 + 大号简图动画）；单场胜利荣誉结算（庆祝 + 首胜小奖杯）。

## Milestone 10 — 三关闯关与领奖台（三轮定稿，已完成）
黑帽新手 → 橙帽好手 → 王冠 Boss 三关递进（帽子=难度符号）；当局连续晋级；三关全通关触发 1/2/3 领奖台冠军结算。

## Milestone 11 — 双难度轨与体验微调（四轮定稿，三关实测反馈）
新手轨难度下调（球速放慢、失误率上调、反应放宽；扣杀飞行时间按关可配、新手王冠 0.95s）；扣球跳起夸张化；引导简图左右对照（左手部动作 + 右小人结果演示）；专业三关（紫影→紫电→魔王，紫色荧光递进，全面加强）；通关新手王冠播登场动画解锁专业轨，localStorage 持久化。

## Gate — 是否继续完整游戏
在目标 ThinkPad 实测：延迟、误触发、漏识别、FPS、连续 rally 是否好玩。
首轮实测（2026-08-11）未通过：卡顿、球快、无引导、画幅小 → 见 TASKS.md M7，完成后重测。
M8 实测（2026-08-12）：核心操控（追踪/握拳击打/连握扣球/引导）验证通过，用户确认核心体验值得继续 → 进入 M9/M10。
M10 实测（2026-08-12 深夜）：王冠扣杀过快打不过、整体偏难无法通关 → 新手轨降难度 + 专业轨承接挑战 → 进入 M11。
