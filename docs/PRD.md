# PRD — Wobble Badminton

## 1. 产品愿景
做一个不用 VR、只靠普通笔记本摄像头就能玩的轻量 3D 体感羽毛球小游戏。玩家真实挥手，屏幕中的呆萌低模角色挥拍。第一感受应是“看起来傻傻的，但居然很好玩”。

## 2. 目标硬件
- 2021 年左右普通 ThinkPad/办公 Windows 笔记本
- 集成显卡也应有机会运行
- 内置或 USB 摄像头
- 可 HDMI 外接电视/显示器
- Chrome/Chromium 浏览器

## 3. 核心用户故事
- 我能快速授权摄像头并看到追踪状态。
- 我挥手时，角色能及时做出挥拍反馈。
- 我不需要精确对准真实空间中的球，也能自然击球。
- 我能与 AI 连续对打并计分。
- 游戏角色和失败/庆祝动作让我觉得有趣。

## 4. MVP 范围
必须有：单一球场、玩家角色、AI、球网、羽毛球、摄像头手部追踪、挥拍识别、辅助击球区、简化球物理、AI 回球、比分、重开、Debug 面板。

暂不做：完整三关、联网、多人、VR、真实软体物理、复杂角色编辑、高质量 PBR、大量粒子、复杂存档、专业羽毛球规则模拟。

## 5. Vertical Slice 验收标准
- 首次进入可明确完成摄像头授权/失败提示。
- 能显示追踪状态与 FPS。
- 正常光照下可识别惯用手挥动，并有灵敏度参数。
- 玩家挥拍能触发角色挥拍与击球尝试。
- 击球使用宽容窗口，不要求像素级空间对应。
- AI 能回球，形成至少基础 rally。
- 有比分、失分、重新发球。
- 720p 下以 30 FPS 为最低目标；实际硬件性能必须以用户实测为准。
- 核心交互不因视觉效果产生明显额外延迟。

## 6. 后续版本（核心通过后）
V1：三关闯关、Good/Great/Perfect、Combo、音效、轻特效、Boss。
V2：更多角色/场景、球拍标记追踪、校准体验、更多挑战模式。
