# PRD — Wobble Badminton

## 1. 产品愿景
做一个不用 VR、只靠普通笔记本摄像头就能玩的轻量 3D 体感羽毛球小游戏。玩家真实挥手，屏幕中的呆萌低模角色挥拍。第一感受应是“看起来傻傻的，但居然很好玩”。

## 2. 目标硬件
- 2021 年左右普通 ThinkPad/办公 Windows 笔记本
- 集成显卡也应有机会运行
- 内置或 USB 摄像头
- 可 HDMI 外接电视/显示器
- Chrome/Chromium 浏览器

## 3. 核心用户故事
- 我能快速授权摄像头并看到追踪状态。
- 我挥手时，角色能及时做出挥拍反馈。
- 我不需要精确对准真实空间中的球，也能自然击球。
- 我能与 AI 连续对打并计分。
- 游戏角色和失败/庆祝动作让我觉得有趣。
- 我能选择快节奏短局或标准局长度。
- 我赢球、闯关时能收获奖杯与领奖台这样的荣誉时刻。
- 我作为新手能顺利通关新手三关；通关后有更强的专业三关等我挑战。

## 4. MVP 范围
必须有：单一球场、玩家角色、AI、球网、羽毛球、摄像头手部追踪、击打识别、辅助击球区、简化球物理、AI 回球、比分、重开、Debug 面板。
首轮实测后新增：新手引导模式（动作教学 + 识别确认）、可调球速/难度（默认高慢球）、大画幅追踪预览与站位指引、身体移动控制角色。
二轮定稿（2026-08-12）新增：
- 双操控模式：空手模式（握拳=击打、手大小=前后移动，默认）与键盘+持物模式（WASD 移动 + 快挥击打），M 键切换。
- 击打做减法：正板直打，无方向控制；连握两次 = 扣球（空中补刀，更快更平）。
- 21 分简化制：先到 21 获胜，胜负结算画面，R 开新局。
- 帮助系统：左上角常驻 ? 图标（H/F1 呼出），含操作说明、动作简图小动画、重进引导入口。
三轮定稿（2026-08-12 晚，M8 实测后）新增：
- 赛制选择：开局可选 6 分快局（默认）或 21 分标准赛；均先到分数直接获胜，无 deuce 加分。
- 跳起扣杀：连握扣球时角色明显跳起扣杀，与普通原地击打一眼可辨。
- 新手友好判定：放宽击球判定窗口，球到附近随手撩一下即可打到，尺度"不太难也不太简单"。
- 引导界面重做：整块黑色遮罩全屏界面 + 更大更精美的动作简图动画，明确演示"握一下=击打、握两下=跳起扣球"。
- 荣誉体系：单场胜利结算动画 + 首胜小奖杯；三关全通关站上 1/2/3 领奖台拿冠军（画风保持低模呆萌不变）。
四轮定稿（2026-08-12 深夜，三关实测后）新增：
- 新手轨整体难度下调：三关球速放慢、失误率上调、AI 反应放宽；王冠扣杀放慢（扣杀飞行时间按关卡可配）。目标：首次玩家能顺利通关新手三关。
- 引导简图升级左右对照：左侧手部动作 + 右侧简笔小人同步演示游戏内结果（握一下=小人挥拍击打、握两下=小人跳起扣杀且动作更快），建立"动作 → 结果"映射。
- 扣球跳起更夸张：跳更高、落地压缩更狠，与普通击打隔屏可辨。
- 双难度轨：新手三关（黑帽→橙帽→王冠）+ 专业三关（紫影→紫电→魔王，同一角色紫色递进 + 荧光感，球速/反应/扣杀全面加强）；通关新手王冠 → 专业玩家登场小动画 → 解锁专业轨；解锁状态 localStorage 持久化，解锁一次永久有效。

暂不做：联网、多人、VR、真实软体物理、复杂角色编辑、高质量 PBR、大量粒子、复杂存档（仅 localStorage 解锁标记）、专业羽毛球规则模拟、回球方向控制。

## 5. Vertical Slice 验收标准
- 首次进入可明确完成摄像头授权/失败提示。
- 能显示追踪状态与 FPS。
- 正常光照下可识别惯用手/握拳，并有灵敏度参数。
- 新手引导：黑底全屏引导界面，4 步内学会"举手识别 → 握拳击打 → 连握扣球 → 移动"，实时识别反馈 + 左右对照大号动画（左手部动作、右小人结果演示）。
- 空手模式：握拳即击打，一握即中；手移动能控制角色左右/前后跑位。
- 键盘+持物模式：WASD 移动、快速挥动击打，M 键切换。
- 击球使用宽容窗口，正板直打；判定对新手友好（球到附近撩手即可打到）。
- 普通击打与连握扣球视觉区别明确：扣球为跳起扣杀，跳起幅度夸张、隔屏可辨。
- AI 能回球，形成至少基础 rally；默认球速为高慢球，可调。
- 赛制可选：6 分快局（默认）/ 21 分标准赛，先到分数直接获胜无 deuce，有胜负结算，R 开新局。
- 单场胜利有荣誉结算（奖杯）；三关全通关有领奖台冠军画面。
- 双难度轨：新手三关首次玩家可通关；通关后播登场动画解锁专业三关（紫色荧光对手），解锁状态刷新后保留（localStorage）。
- 720p 下以 30 FPS 为最低目标；追踪推理不得拖垮渲染；实际硬件性能必须以用户实测为准。
- 核心交互不因视觉效果产生明显额外延迟。

## 6. 后续版本
当前计划（四轮定稿确认）：M11 双难度轨——新手轨降难度（首次可通关）、引导左右对照、扣球夸张化、专业三关解锁（紫色荧光 + localStorage 持久化）。
V2：Good/Great/Perfect 时机评价、Combo、更多音效/特效、更多角色/场景、球拍标记追踪（颜色标记兜底纯手部识别）、校准体验、更多挑战模式、网球变体（同引擎换弹性模型）。

## 7. 实测记录
首轮（2026-08-11，ThinkPad）未通过，主要问题：主线程同步推理卡顿冻结；球速过快无法回击；无新手引导不知如何击打；追踪预览画幅太小；持拍识别与挥拍灵敏度待调；debug 面板干扰。处理：插入 M7 体验修复（见 TASKS.md），完成后重测。
二轮 M8 实测（2026-08-12）：手部追踪稳定、握拳击打/连握扣球可用、新手引导正常，核心操控验证通过。改进项：21 分过长（改可选 6 分短局）；扣球无跳起动画；击球判定偏难；引导界面太小；缺荣誉结算。处理：M9/M10（见 TASKS.md）。
三轮 M10 实测（2026-08-12 深夜）：引导黑底大动画获好评；6 分节奏与 21 分入口 OK。问题：王冠扣杀过快打不过、三关整体偏难（首次玩家无法通关）；扣球跳起不够明显；引导建议加小人结果对照。处理：M11 双难度轨（见 TASKS.md）。
